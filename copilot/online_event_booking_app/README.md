# Online Event Booking App

A simple full-stack event booking project using:

- Backend: Flask
- Database: SQLite
- Frontend: HTML, CSS, JavaScript

## Run the project

1. Open a terminal in this folder.
2. Install Flask:

```bash
pip install -r requirements.txt
```

3. Start the app:

```bash
python app.py
```

4. Open the local URL shown in the terminal, usually:

```text
http://127.0.0.1:5000
```

## Features

- View available events
- Book tickets for an event
- Store bookings in SQLite
- Update available seats after each booking
- Show recent bookings on the homepage
